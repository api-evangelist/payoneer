# Payoneer GraphQL API

Payoneer is a global payment and commerce platform for cross-border B2B payments. The API covers payee management, payments, balance accounts, currency exchange, and tax compliance for marketplaces and freelancer platforms.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Payoneer REST API
**Documentation:** https://www.payoneer.com/developers/

- Reference: https://developer.payoneer.com/docs/mass-payouts-v4-getting-started.html
- Schema: https://github.com/api-evangelist/payoneer
